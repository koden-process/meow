# Glossaire

| Terme | Définition |
|---|---|
| Account | Compte client ou contact géré dans Meow. |
| Activity | Flux d'activité construit à partir des événements métier. |
| Card | Opportunité commerciale affichée dans le pipeline. |
| Forecast | Prévision commerciale calculée à partir des opportunités, lanes et dates. |
| Lane | Étape du pipeline commercial. |
| Schema | Configuration des champs personnalisés pour Cards ou Accounts. |
| Team | Organisation ou équipe propriétaire des données. |
| User | Utilisateur appartenant à une Team. |
| Event | Enregistrement métier décrivant un changement ou un état forecast. |
| OpportunityTransfer | Demande de transfert d'une opportunité vers une autre équipe. |
| `DatabaseHelper` | Point d'entrée unique vers MongoDB. |
| `EventStrategy` | Abstraction de l'event bus backend. |
| `RequestHelper` | Client HTTP frontend centralisé. |
